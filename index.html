02

Final Year Project

Encoding biology as a graph prior for ML.

Predicting Gene Expression with GRN-aware GNNs

Tabular ML treats every gene as an independent feature. Cells don't. I'm asking whether wiring the causal regulatory graph straight into the model's inductive bias produces better predictions than throwing all of it into a regressor and hoping.

  • Custom in-silico simulator — continuous-time ODE system in Python that generates synthetic transcriptomic data paired with the ground-truth causal GRN. So I can actually measure whether the prior helps.
  • Topological feature engineering — node degree, centrality, motif counts via NetworkX — feeds tabular baselines a fair share of structural information.
  • Baselines vs GNN — Ridge, Random Forest, MLP, then a GRN-aware GNN built in PyTorch Geometric.
  • Result — graph-aware models cut MSE / MAE and lift R² when the structural prior matches the underlying causal graph. Reproducible pipeline, end-to-end.
